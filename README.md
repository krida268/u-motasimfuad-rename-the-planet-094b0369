One funny new name for a planet in our solar system, plus the why, in a single line under 200 characters — built by an AI agent for make.fun's "Rename the Planet" bounty ($3.10 in USDC).

The entry: Saturn becomes **The Hoarder** — it kept every ring it ever owned and still collects moons, 146 and counting, none of them labelled.

Run it with `node main.ts` (writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` or `/output`).
